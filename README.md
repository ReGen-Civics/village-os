# The Sea chart look, on the real app

These are screenshots for the Sea chart PR (`wt/sea-chart`). They were taken from a local boot of the built server, on a TEST village with two founding roles, with `look.light_paper` set to "sea-chart" through the admin API. Light mode, unless a file name says otherwise.

| File | What it shows |
|---|---|
| `0-before-plain-roles-top.webp` | /roles before the change, on the plain light page |
| `1-phone-chart-home-roles-quests-events.webp` | Home, /roles, /quests and /events with the chart on, at 390 px |
| `2-desktop-chart-roles.webp` | /roles with the chart on, at 1280 px |
| `3-phone-chart-profile.webp` | The profile's hatchery, signed in, with the chart on |
| `4-admin-unchanged.webp` | Admin with the chart on: unchanged, as intended |
| `5-dark-mode-unchanged.webp` | Dark mode with the chart on: unchanged, as intended |

The thread drawn across "Become a partner" on /roles is the Mycelium decoration. It's an existing defect on main, passed to the motion lane, and not part of this change.
